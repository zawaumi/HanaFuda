# 次の会話を準備するHanaFudaエージェント（未着手の提案）

この文書はハッカソン後続作業のための計画メモです。現時点では実装しません。

## ねらい

大学生の日常にある「人との会話を準備し、振り返り、次につなげる」作業を自律化する。仕事向けの1on1や営業を前提にしない。会話記録の保存後、追加操作なしで次回の準備が進むことをデモの核とする。

## 想定する動き

1. 相手を指定した会話記録の保存をきっかけに、エージェントが評価・メモ・過去の会話・確認済みの記憶を読む。
2. 続きの話題や聞きそびれたことを判断し、話題カードを作る。過去のカードとの重複や避けたい話題を点検し、必要なら作り直す。
3. 結果を下書きとして保存し、ホームと相手の詳細に「次に会ったときの準備」を表示する。話題を選んだ理由も短く示す。
4. メモから見つけた相手の情報は記憶候補に留め、ユーザーが確認したものだけを保存する。

## 分担・境界

- バックエンド担当: 保存後の自動処理、結果の保存・取得、失敗時の状態管理。
- フロントエンド担当: 準備中・完了・失敗の表示、カードの確認、記憶候補の承認。
- 相手を指定しない会話では自動準備しない。外部サービス連携や自動メッセージ送信は含めない。
- AIの準備が失敗しても、元の会話記録は失わない。

## デモの合格条件

サークル仲間などとの会話メモを保存すると、追加操作なしで、その内容を踏まえた次回用の話題が現れる。記憶候補は未承認のまま確定しない。
